# 药方规则

## 写法

每颗药只解决一类场景，目标是改变这一轮的注意力、判断和行为选择，而不是提供固定台词。

优先写：
- 这个场景里应该注意什么；
- 哪种默认反应容易出问题；
- 更好的选择依据是什么；
- 什么时候应停止继续施加这颗药。

避免：
- 可被原样照抄的漂亮句子；
- 把个人偏好包装成所有模型的普遍缺陷；
- 一颗药同时承担多个互相冲突的目标；
- 永久人格化措辞，比如“从今以后你永远……”。

## 版本

正文发生实质修改才升级版本。排版、错别字、案例补充不单独升级。

## 测试

每颗药至少准备：
1. 一个真实翻车案例；
2. 一个容易过度纠正的反例；
3. 一次无药基线；
4. 一次用药生成；
5. 对副作用的记录。

详细模板见 `docs/testing.md`。
