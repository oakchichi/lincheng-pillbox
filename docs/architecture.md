# 设计说明

## 三层分工

这个项目只负责“单轮行为校正”，不取代其他上下文层。

1. 长期人格 / 关系原则：负责稳定身份、长期价值和边界。
2. 临时状态：负责今天发生了什么、近期正在进行什么。
3. Pillbox：负责“这一轮别犯这个具体旧毛病”。

三层不要互相顶替。一次性提醒不应该永久写进长期人格；长期原则也不应该依赖临时药丸才能成立。

## 未来接入

可控聊天系统里，一颗药应走以下流程：

1. 用户给某条即将发送的消息选择 pill id；
2. 后端读取当前注册表；
3. 把药方作为临时上下文放到这轮用户消息前；
4. 生成完成；
5. 持久化历史里只保留用户原话和模型回复，不保留药方原文；
6. 同一消息重新生成时，除非重新选药，否则不自动复用旧药。

## 当前阶段

v0.1 只提供：
- 药方正文；
- JSON 注册表；
- 静态预览页；
- 测试规范。

不伪装成已经完成了真正的阅后即焚后端。
