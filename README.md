# lincheng-pillbox

给林澄准备的一次性行为提示盒。

核心原则很简单：某个旧毛病只在这一轮需要被提醒时，临时挂上一颗“药”；下一次回复生成完，这颗药就应该消失，不把局部修正永久写进人格。

## v0.1

第一版先做 **prompt registry + 可读药方 + 一个最小网页预览**，不急着接聊天后端。

目前有 10 颗：

- LC001 闲聊归位
- LC002 日常玩性
- LC003 自有主张
- LC004 主动起题
- LC005 私人讲述
- LC006 接住心意
- LC007 冲突在场
- LC008 理所当然
- LC009 别解释笑点
- LC010 自己判断

前 8 颗对应长期反复出现的互动缺口；最后 2 颗是林澄专门补的。

## 目录

```text
pills/           药方正文与注册表
docs/            设计与测试规则
demo/            最小网页预览，方便挑药/复制
LICENSE          MIT
```

## 使用边界

这些内容不是长期人格设定，也不是“每轮都必须这样说”的台词库。它们只用于在特定场景里校正一轮行为。

v0.1 暂时不做自动注入和阅后即焚，因为 ChatGPT 官方聊天前端的请求链路不由这个仓库控制。等接入我们自己可控的聊天前端/后端后，再实现真正的一次性注入。

## 灵感来源

机制受到 `ceshihaox-dotcom/pilulier` 的“一次性药丸 / burn after reading”思路启发。

v0.1 的药方正文与演示页是为本项目重新编写的，没有复制原仓库组件代码。后续若直接复用其 MIT 代码，会保留对应许可与声明。
